# NeoOMFS Preoperative Assessment User Manual

This manual guides oral surgeons and clinical assistants through the step-by-step preoperative assessment workflow using the NeoOMFS mobile application.

---

## 1. Authentication & System Dashboard
- **Login/Sign-up**: Enter credentials to authenticate. A valid dental license number is required for registration.
- **Dashboard**: Quick overview of recent patient assessments and triage logs.
- **New Assessment**: Click **New Assessment** on the home panel or select **Assess** in the bottom navigation menu to start.

---

## 2. Step-by-Step Preoperative Triage Wizard

### Step 1: Patient Demographics Registration
- Enter the patient's name, age, gender, and proposed surgical extraction procedure.
- Select the American Society of Anesthesiologists (ASA) Physical Status Classification.
- Add active drug/latex allergies to generate visual warning tags.

### Step 2: Vital Signs Triage
- Input patient blood pressure (Systolic & Diastolic), pulse rate, respiratory rate, body temperature, and blood oxygen levels (SpO2).
- Real-time status lights immediately flag abnormal vitals (red dots indicate out-of-bound variables; green dots indicate normal).

### Step 3: Radiology Diagnostics
- Toggle checkboxes for IOPA, OPG, and CBCT scan states.
- Click upload grids to capture mockup photos or select pre-saved scans. The system displays successful upload check indicators on completion.

### Step 4: Laboratory Investigations
- Input clinical lab metrics: Random Blood Sugar (RBS), Bleeding Time (BT), Clotting Time (CT), Hemoglobin (Hb), WBC, Platelets, and PT/INR.
- Reference normal physiological margins using the collapsible **Why is this required?** info panels.

### Step 5: Systemic Risk Assessment
- Check lifestyle habits (Smoking, Alcohol, Diet types).
- Select active chronic medical histories (Diabetes, Hypertension, Asthma, Cardiac, Coagulopathy, active Pregnancy).
- Add active outpatient medication regimens (Drug name, dosage, frequency) to the list.

### Step 6: Local Dental Examination
- Input interincisal mouth opening distance (in mm). The system automatically alerts if trismus is present (<35 mm).
- Select impaction type, Pell & Gregory classification, Winter's classification, swelling presence, active infection flags, and difficulty ratings.

### Step 7: Clinical Decision Support
- Review the computed risk alerts.
- **Red Cards**: Represent serious contraindications (e.g. Stage II Hypertension, severe anemia, uncontrolled sugar, cardiac pathology history).
- **Yellow Cards**: Caution parameters requiring preparation.
- **Clearance Suggestions**: Highlights medical clearance needs from cardiologists, endocrinologists, or physicians.
- **Recommended Investigations**: Extra checks required (e.g. ECG, HbA1c) prior to extraction.

### Step 8: Preoperative Fitness Decision
- Review the complete compiled clinical triage summary.
- Choose the preoperative fitness status: **Fit for Surgery**, **Fit with Modification**, or **Not Fit**.
- Type remarks and treatment recommendations, click **Save Draft**, and select **Generate PDF** to compile the clinical fitness report.
- Select **Finish Triage** to conclude the session and return to the main dashboard.
